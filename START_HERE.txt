ORBIT 3.0 — START HERE
======================

This ZIP is the Windows application SOURCE. It is NOT yet an EXE.

FASTEST PATH TO A REAL ORBIT.EXE WITHOUT TERMINALS:
1. Create a NEW GitHub repo for ORBIT Windows (not your orbit-mobile repo).
2. Upload ALL contents inside this ORBIT_3_0 folder to its root, including .github.
3. Open GitHub -> Actions -> Build ORBIT 3.0 for Windows -> Run workflow.
4. Download the ORBIT-3.0-Windows artifact from the successful workflow.
5. Install with ORBIT_3_0_Setup.exe; afterwards start ORBIT from the Start menu.

OR, on a Windows developer PC with .NET 10 SDK:
Run BUILD_WINDOWS.bat; optionally install Inno Setup 6 to make the installer.

VOICE: Windows offline voices are the fallback. To get improved Romanian/English
neural voices, set up your own Azure Speech region and resource key in ORBIT
Settings. The Romanian Piper crash cannot block startup because Piper was removed.
If Windows lacks a Romanian speech voice, install one or use online neural.

YOUR OLD REMINDERS: Export an ORBIT 2.8.1 JSON backup, then import inside
ORBIT 3.0 Reminders. The local profile does not migrate automatically.

PC <-> IPHONE: Enter your existing Supabase URL and PUBLISHABLE key in
Settings -> ORBIT Cloud. Sign in with the SAME cloud account as iPhone.
Never put secret/service_role keys in this source or GitHub.

STATUS: UI tests passed in Chromium. The native exe, voices, installer and
live cloud were not tested in Windows here. Read README.md for details.
